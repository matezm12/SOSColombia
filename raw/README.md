# Raw Snapshots

Verbatim copies of fetched docs/pages. Naming: `<source-slug>-<YYYY-MM-DD>.md` (or `.pdf`/`.html` if binary/rendered).

Why this exists: govt pages get edited or taken down, news sites paywall later. Re-derive wiki facts from these snapshots instead of re-fetching live. Also gives exact wording to cite.

Every raw snapshot added here should get a row in `wiki/06-sources.md` pointing to it.
