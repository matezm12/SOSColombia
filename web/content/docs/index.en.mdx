SOSColombia is an independent, volunteer-run project that centralizes verified information about the August 10, 2026 earthquake in Colombia: official figures, aid-point directories by city and vereda, verified donation campaigns, and moderated community posts.

This documentation has two audiences: if you're a site visitor, **How it works** explains where the data comes from and how to navigate; if you're a developer, researcher, or want to reuse the data, **How it's built** and **Data & API** cover the technical stack and how to export information.
