# Glossary — Colombian Disaster Response Terms

| Term/Acronym | Meaning |
|---|---|
| UNGRD | Unidad Nacional para la Gestión del Riesgo de Desastres — national disaster risk management unit |
| SGC | Servicio Geológico Colombiano — geological survey, source of seismic facts |
| DNP | Departamento Nacional de Planeación |
| DANE | Departamento Administrativo Nacional de Estadística — census/demographics |
| INMLCF | Instituto Nacional de Medicina Legal y Ciencias Forenses — official death confirmations |
| Damnificado | Person who lost their home/severely affected, typically displaced |
| Afectado | Person impacted but not necessarily displaced (broader, less severe than damnificado) |
| Albergue | Shelter |
| Comedor comunitario | Community food/soup kitchen |
| Centro de acopio | Donation/supply collection point (NOT a distribution point for affected people — donors drop items here) |
| Informe de situación | UNGRD situation report, typically recurring (daily/near-daily so far this event) |
| PMU | Puesto de Mando Unificado — unified command post for disaster response |
| USAR | Urban Search and Rescue team — 4 activated for this event from Bogotá, Envigado, Yopal, Medellín |
| Decreto de emergencia | Emergency declaration (economic/social/ecological) issued by Presidencia |
| Emergencia económica | Specific type of emergency decree enabling extraordinary economic/fiscal measures — announced 2026-08-12 for this event |
| Fondo Milagro | Disaster relief fund created by national government for this earthquake (announced 2026-08-12) — needs follow-up on scope/funding |
| Gobernación | Departmental government |
| Alcaldía | Municipal/city government |
| Banco de Alimentos | Food bank — recurring org type appearing across multiple cities as a collection/distribution point |
| Cruz Roja | Colombian Red Cross — primary NGO coordinating collection points nationally for this event |
| SCARE | Coordinating body for the 16-city "Sociedades Científicas" medical supply network activated for this event |
| Colombia Te Busca | Civic/volunteer crowdsourced platform where families self-report missing relatives (modeled on Venezuela's "Desaparecidos Terremoto Venezuela") — its report count (~4,000+) is NOT the same metric as UNGRD's official confirmed-missing count (287), see wiki/08-contradictions.md |
| CEDE | Centro de Desarrollo Empresarial — pre-existing municipal facilities in Pereira repurposed as donation collection points after the earthquake |
| Calamidad pública y urgencia manifiesta | A departmental/municipal-level emergency declaration (distinct from the national "emergencia económica") — e.g. Risaralda's Gobernación declared this Aug 11, unanimous vote by the Consejo Departamental de Gestión del Riesgo |
| Acopio vs. albergue | Critical distinction for this project: "centro de acopio" = donation collection point (donors drop items off); "albergue" = shelter (displaced people actually stay/receive aid). Confirmed via mapadelterremoto.com's own page structure — do not conflate the two. |
