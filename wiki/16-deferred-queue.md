# Deferred Queue

**Purpose:** the discipline artifact for staying on task. Mid-pass, if something interesting surfaces that isn't the pass's explicit target, it gets ONE line here — not chased in the moment. At the end of each pass, the queue gets triaged: promoted into a future pass, or explicitly dropped. This file is checked, not automatically acted on.

**Rule:** no research session opens this file and starts working through it top-to-bottom. It only gets consulted at a pass boundary, when explicitly deciding what's next.

## How to log an entry
`- [source/context] one-line description of the lead — why it might matter` — that's it, no deep-dive, no follow-up links unless already in hand.
